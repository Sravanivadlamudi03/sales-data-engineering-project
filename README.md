# Sales Data Engineering Project

## Overview
End-to-End Sales Data Engineering Project using Python, Pandas, ETL, Data Transformation, SQL, and Power BI.

## Project Structure

- Sales_Data_Engineering_Project.ipynb
- customers.csv
- products.csv
- sales.csv

## Technologies Used

- Python
- Pandas
- Jupyter Notebook
- SQL
- Power BI
- GitHub

## Project Workflow

1. Load sales, customer, and product datasets
2. Perform ETL and data cleaning
3. Transform and join datasets
4. Generate analytical datasets
5. Create dashboards in Power BI
